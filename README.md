## About Me

I'm a Bachelor of Information and Communications Technology graduate from the Durban University of Technology (2026), currently working as a Test Automation Trainee at **Ndosi Test Automation**.

My work sits at the intersection of two things I genuinely enjoy: building software and making sure it actually works. I started out writing code, and over time I became just as interested in how software behaves, where it breaks, and how automation can make it more reliable. Today I split my focus between software development and software quality assurance, and I like that the two feed into each other.

---

## My Journey

I began during my ICT studies at DUT, where I learned the fundamentals of programming and built small applications in Java, Python, C# and web technologies. Writing code made me curious about the other side of the process — what happens after a feature is "done" — so I started paying closer attention to testing and quality.

That curiosity led me to Ndosi Test Automation, where I'm completing a **6-month Software Test Automation training programme**. It's been hands-on from the start: building automation frameworks, writing real test cases, and learning how quality assurance fits into the wider software development lifecycle. Coming from a development background has helped here — understanding how something is built makes it easier to figure out how it might fail.

I'm still early in my career, but I now have a solid practical foundation across both development and test automation, and I'm continuing to build on it.
