## About Me

I am a Bachelor of Information and Communications Technology graduate from the Durban University of Technology (2026), currently completing hands-on training as a Test Automation Trainee at **Ndosi Test Automation**.

My focus spans three complementary areas:

- **Software Engineering and Application Development**
- **Backend Development and REST API Engineering**
- **Software Quality Engineering and Test Automation (SDET)**

I enjoy understanding how software is built, using backend and API technologies to create practical solutions, and applying structured testing to improve quality and reliability. I am early in my career and am continuing to develop both my development and automation skills through project work, professional training and graduate-level opportunities.

## My Journey

During my ICT studies at DUT, I built a foundation in programming and application development using Java, C#, Python, JavaScript and web technologies. This led me to become interested not only in writing software, but also in how applications behave, how failures are identified and how automated tests support the software development lifecycle.

At Ndosi Test Automation, I am completing a **6-month Software Test Automation training programme**. My training includes Java-based Selenium automation, API testing, Cucumber BDD, Playwright, performance testing and mobile automation, alongside reusable framework design and test reporting practices.
